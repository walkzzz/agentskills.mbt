保留全部 system + 最近 keep_recent 条对话；更早消息折叠为计数占位；逐条按 max_chars 截断。折叠无收益（占位更长）时自动跳过，输出含 saved_chars / folded。

Unicode 安全截断

truncate_text

按 codepoint 截断，绝不劈开多字节字符；截断时追加省略号。max_chars 必须 ≥ 1（越界由页面拒绝；库层 ≤0 返回空串）。

等待截断…

RRF 融合

rrf_demo

多路排名 → Σ 1/(k+rank)；分数降序，同分按 doc_id 升序 tie-break；top_n 为全量前缀。k 必须 > 0（否则分母为 0 产生 Infinity），k/top_n 为 int32 演示范围。

等待融合…

total_chars

  @skill.parse_skill_md(skill_md).unwrap()

Under the hood

这是怎么在浏览器里跑的？

  1. 1

    agentskills/playground 是主模块的 foreign_library 包，用 #export_name 导出 12 个非 raise 包装函数（错误折叠为 {"ok":false} / false / -1）。

  2. 2

    moon build --target js --release agentskills/playground 生成一份 JS；同一份源码也可构建为 wasm-gc / native。

  3. 3

    页面直接 import 并调用：解析、校验、注册、RBAC、压缩、截断、RRF、字符统计与 MCP 条目全部在本地完成。

  4. 4

    语义由 61 项测试、24 点变异矩阵与 8 条证明义务守护；check_pages.mjs 验证导出与语义，Pages 部署 docs/。
