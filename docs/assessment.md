# 立项评估（agentskills.mbt 0.2.0）

> 自评口径：上游库门禁九维 + 创新性 / 合规性；每维折算 100 分制。
> 结论：**建议立项（A 级，93 分）**；主要风险为单人维护与部分功能面（MQ/国密、wasmoon）未闭环。

## 2. 风险与缓解

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 单人维护 | 长期演进不确定 | 冻结契约 + 差分测试 + CI 全绿；可 fork |
| CLI argv 缺失（GAP-1） | 子命令面受限 | 环境变量/内嵌剧本过渡；随 @process 集成裁决 |
| wasmoon 未集成（GAP-7） | 沙箱仅 js 执行器 | 三执行器策略，js 执行器已实测 |
| PG 与同步 Storage trait 接口差（GAP-8） | 后端统一性 | async 独立 API + 运行时壳适配层 |
| BUG-001（UP-019 分歧） | 差分 1 例隔离 | known_failure 登记；修复后自动复活 |

## 3. 立项建议

1. **定位**：作为 MoonBit 项目的技能运行时资产，按 SemVer 维护（0.x 阶段以 `.mbti` 冻结契约）。
2. **采纳方式**：优先使用 Kernel 包（`skill/rag/rbac/compactor`）；存储与认证按需引入。
3. **验收门槛**：`moon check --deny-warn --target all` + 四目标测试 + 变异全 KILLED + `check_pages.mjs` 123 项。
4. **后续**：0.3.0 评估 wasmoon 执行器、CLI 子命令面与 MQ/国密联动。
